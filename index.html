05

Open source

Small, useful tools I publish in the open.

api-contract-diff ↗

Catches removed endpoints, dropped response fields and type changes between OpenAPI specs. A TypeScript CLI with readable reports and CI-friendly exit codes.

  • TypeScript
  • CLI
  • CI

checkout-canary ↗

A config-driven Playwright monitor that walks a store from the home page to the payment step on a schedule, alerts you, and publishes a green/red status page. Free, no server needed.

  • Playwright
  • GitHub Actions
  • Adobe Commerce
  • WooCommerce

agent-gauntlet ↗

A deterministic, no-LLM audit of a store's checkout journey. It runs the way an AI shopping agent does, with no human-like pauses, and reports where the journey breaks, with screenshots. It stops before payment and never places an order. Early release (v0.1.0).

  • Python
  • Playwright
  • CLI
  • Adobe Commerce
  • WooCommerce
  • MIT

contact-cta-inspector ↗

A privacy-first Chrome extension that scans a page for WhatsApp, phone and email links and checks their format, keeps general link observations separate, suggests fixes, and copies a redacted report. Offline and deterministic, with no network calls, accounts or analytics.

  • TypeScript
  • Chrome extension
  • Manifest V3
  • Privacy
  • MIT

awi (Agent Workflow Inspector) ↗

An offline, deterministic linter for AI agent traces. It reads AWI JSON or OpenTelemetry exports and flags retry storms, repeated failing tool calls, execution cycles, runaway delegation and resource burn, with exit codes for CI gating. No accounts, LLM keys or network access. Version 1.0.0 release candidate.

  • TypeScript
  • OpenTelemetry
  • CLI
  • AI agents
  • MIT

logpulse-ai ↗

A terminal log debugger and incident copilot. It reads piped logs, a file, or a wrapped command that failed, masks listed secret and PII patterns locally, then asks Gemini for a root cause and a ready-to-apply git diff, and can export a post-mortem in Markdown.

  • Python
  • Gemini API
  • CLI
  • SRE
  • MIT
